# v0.52.70 — The Ashen Threshold

TEUS's v0.52.x line moved the game into a spatial, three-quarter experience. Players can explore authored locations through local maps, move through the world, interact with nearby characters and discoveries, follow investigations, encounter persistent threats, and travel between connected places. Directional player animation and dedicated NPC, hostile, and remains artwork support the new presentation.

The release rebuilt the core interface around retained presentation and clearer screen transitions, expanded character creation and records, added composited dialogue portraits, and introduced Character Lab and World Lab authoring tools. Desktop and Android received the controls and navigation needed to use the spatial-first flow.

The underlying game gained managed internal storage with save import/export, installed-mod management and mod-aware content/assets, authored local layouts with rooms and doors, character-specific evidence and quest tracking, and more deterministic persistent encounter spawning. The v0.52.x line completed integrated desktop and Android verification of the spatial-first experience.
