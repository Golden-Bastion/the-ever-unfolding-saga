# vMAJOR.MINOR.PATCH — Release Codename

Replace this template before creating the release tag.

Write a short, player-facing summary of this specific release. Keep it focused on the most meaningful additions, improvements, and fixes rather than copying the development changelog. Use a few concise paragraphs or grouped bullet points.

The first line must match the release tag exactly, for example:

# v0.53.0 — Example Codename

CI/CD validates that version and uses the heading as the GitHub Release title. Everything below the heading becomes the release description.
